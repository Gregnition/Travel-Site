# 🌍 Travel Site – City Explorer

A modern, responsive travel landing page built with HTML, CSS, and JavaScript. Features full-screen background videos, slide transitions, navigation dots, and a mobile-friendly menu. Users can explore iconic cities like New York, Tokyo, and Paris in an immersive way.

---

## ✨ Features
-  Fullscreen video backgrounds for each city  
-  Smooth slider navigation with animated transitions  
-  Responsive design with mobile-friendly hamburger menu  
-  Social media links for extended engagement  
-  Modern UI styled with Google Fonts and Font Awesome icons  

---

Live Demo

👉 https://gregnition.github.io/Travel-Site/

---

🔧 How It Works

The homepage displays a video slider with multiple city clips.
Users can switch slides using the navigation dots, which updates the video, text, and animations.
The hamburger menu ensures a smooth mobile experience.
Each city section includes a headline, description, and button to simulate exploring travel options.
